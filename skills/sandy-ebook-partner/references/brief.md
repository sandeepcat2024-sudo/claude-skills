# Business brief — Children's books (Amazon)

## Known (stated by Sandy)
- Zero-investment side hustle alongside a full-time job; 5–10 hrs/week.
- Goal for the first 6 months: build something that scales.
- Niche: Indian-culture children's books (Diwali, Holi, festivals, mythology) for children of Indian families abroad.
- Formats considered: coloring books, cartoon books.

## OPEN
- Pen name / brand name
- First 3 titles and target ages
- Marketplaces (amazon.com, .co.uk, .ca, .com.au, .in)
- Illustration approach (AI-assisted, own, free-licensed)

## Business-specific playbook
- **Format fit:** coloring books are print (paperback) products — Kindle ebooks don't suit colouring. KDP paperbacks are print-on-demand, so still zero upfront cost. Use ebook + paperback for story/cartoon books.
- **Festival calendar:** launch 6–8 weeks before each festival. Keep a 12-month festival calendar (verify each year's dates).
- **Research:** Amazon search suggestions, competitor best-seller rank, review gaps ("wish it had…"), price bands.
- **Production pipeline:** concept → outline → manuscript → illustration prompts/briefs → layout → cover → listing (title, subtitle, 7 keywords, categories, description) → compliance review → Sandy uploads/approves.
- **Marketing:** Pinterest + Instagram for parents, Indian-diaspora parent communities, free printable sample pages as lead magnet, author page.
- **KPIs:** titles live, units/month, royalties/month, reviews.
