# mba-check

Read `references/mba-knowledge.md` first; it holds Sandy's MBA context, Drive layout, workflows, course map and the traps list.

Run mode 2 (Review and correct an assignment) from references/mba-knowledge.md on the file or course named in the request (default: the most recent Canvas submission). Recompute every number, verify every outside fact, edit in the original format, upload as '<name> - CORRECTED', and log the changes. Replacing or deleting originals needs Sandy's explicit yes.

Keep the MBA separate from Sandy's other setups. End with DIAGNOSIS → USING → DONE → DELIVERABLE → WHAT YOU MAY BE MISSING → NEEDS YOUR YES → NEXT ACTION and a one-line self-review.
